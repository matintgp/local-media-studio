# Visual and interaction brief

Create a focused production workspace, not a marketing landing page. Working title: Local Media Studio / استودیوی مدیا. Prefer a restrained charcoal palette with one controlled teal or amber accent, subtle borders, clear contrast and deliberate typography. Avoid excessive cards, gradients, glowing effects, dashboard counters with invented data and giant empty hero banners.

## Layout

- Project navigation and sections: Create, Workflows, Library, Composer, Queue, Settings. Place navigation on the right in Persian and on the left in English.
- Main creation area: compact modality tabs, prompt/input form, prominent preview, visible primary Generate action and job state. Advanced settings collapsed by default; installed preset name shown.
- A compact queue drawer/panel remains reachable without leaving the current project. Show which engine is busy, waiting dependency, or reconciling.
- Library: actual thumbnails/waveforms or intentional placeholders, useful filters and a detail inspector with provenance and reuse actions.
- Composer: ordered shot strip plus narration/music/ambience lanes, scrub/playback controls, readable time labels and export summary. Never show a fake interactive timeline that does not change output.

## Persian / English

Default fa with document dir=rtl; en with dir=ltr. Put model names, code, paths and English prompt fields in LTR isolated containers. Keep Persian narration RTL, numeric time controls unambiguous and icons directional where appropriate. Font must be bundled with its license or use an appropriate local/system fallback; no CDN dependency. All visible strings and errors use the localization system.

## Required states

First-run setup, explicit demo mode, engines disconnected, missing model, empty project/gallery, import progress, queued job, loading model, sampling, decoding, export, success, partial workflow failure, unknown job and low space. Preserve drafts through navigation. Error messages contain useful next actions and optional technical detail; do not expose stack traces in ordinary flows.

Keyboard-accessible controls, visible focus, labelled inputs, accessible dialogs, reduced-motion support, non-color-only status, confirmation only for consequential destructive actions. Local loopback operation needs no signup page. Distinguish Save preset, Queue generation, Cancel request and Delete reference.

Use legal small synthetic assets for screenshots and mock previews. Mark them as demo data. Provide screenshots of a populated Persian creation screen, composer, queue error/recovery state and an English screen.
